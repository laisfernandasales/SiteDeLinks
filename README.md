
# 🔗 SiteDeLinks

Site de links pessoais desenvolvido com **HTML** e **CSS puro**, criado durante o curso da **Bia Codes** na Comunidade Dev Completo.

---

## 🖥️ Demo ao vivo

🔗 [Acesse o projeto](https://site-de-links.vercel.app)

---

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3

---

## 📁 Estrutura do Projeto

```
SiteDeLinks/
├── assets/        # Imagens e ícones
├── index.html     # Estrutura da página
├── styles.css     # Estilização principal
└── reset.css      # Reset de estilos padrão
```

---

## 💡 O que aprendi

- Estruturação semântica com HTML5
- Estilização e layout com CSS3
- Reset de estilos com `reset.css`
- Deploy de projetos na Vercel

---

## 🛠️ Como rodar localmente

```bash
# Clone o repositório
git clone https://github.com/laisfernandasales/SiteDeLinks.git

# Acesse a pasta do projeto
cd SiteDeLinks

# Abra o arquivo index.html no navegador
```

> Não requer instalação de dependências — é HTML e CSS puro! ✨
